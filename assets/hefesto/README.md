# Hefesto

Escultura modelada para este museo: herrero barbudo con píleo y exomis, martillo de bronce y yunque.

- `hefesto.glb`: versión para ordenador (≈112 000 triángulos, Draco).
- `hefesto-movil.glb`: versión para móvil (≈52 000 triángulos).

Se genera con `tools/esculturas/hephaestus_build.py`, a partir de la malla base de MakeHuman (CC0 1.0).
