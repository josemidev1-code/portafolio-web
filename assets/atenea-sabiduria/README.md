# Atenea de la sabiduría

Escultura modelada para este museo a partir del retrato de referencia. Tiene corona de hojas, cabello ondulado con raya al medio, expresión serena, quitón con broche en el hombro y la lanza de Atenea.

- `atenea.glb`: versión para ordenador (≈165 000 triángulos, Draco).
- `atenea-movil.glb`: versión para móvil (≈75 000 triángulos).

La oclusión ambiental está horneada en el color de vértice. El mármol se aplica en la página con una proyección triplanar.

Se genera con los scripts de `tools/esculturas/`, a partir de la malla base de MakeHuman (CC0 1.0). Detalles en `tools/esculturas/README.md`.
